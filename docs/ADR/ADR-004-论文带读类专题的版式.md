# ADR-004：论文带读类专题的版式

- 日期：2026-11-13
- 状态：已采纳

## 背景
之前的专题（CFG、Softmax、交叉熵、LDM）都来自一段学习对话，讲的是一个概念，页面模板包含交互计算演示和复习区（公式速查、易错点、自测卡片）。LAPO 是第一个从“论文带读笔记 + 原论文 PDF”做出来的专题。按原模板拟的大纲里有玩具模型的计算演示、复习区和“局限与后续”一章，Guanlin 看后逐条去掉了。

## 考虑的方案
1. 沿用概念类模板：结构统一，但论文页会被演示和复习区撑得很长，偏离论文本身。
2. **论文类单独一套版式（采纳）**：只保留讲清论文需要的部分。

## 决定
- 不加公式速查、易错点、自测卡片，`meta.steps` 只到最后一步。
- 笔记里的思考题、补充问答融进正文，或者写成 `Aside`，不做成 `Quiz`。
- 不做计算演示，专注论文内容，简要讲清楚。
- 笔记涉及的论文原图放进页面，图注写“论文图 N”方便对照原文；架构、数据流、谁看到什么输入，用 SVG 充分画出来。
- 语言通俗易懂又不失专业，保留术语和关键数字。
- 延伸章节（局限、后续工作、与其他论文的对比）在大纲阶段问清楚要不要。

## 后果
- 论文类专题没有自测卡片，首页的“已掌握卡片”统计不包含它们。
- 复习模式下这类专题只剩要点框和 Pitfall，要点框要写得能独立回忆每一步的结论。
- 规则同时写进了 skill `learn-topic-page` 的“论文带读类专题”一节。
